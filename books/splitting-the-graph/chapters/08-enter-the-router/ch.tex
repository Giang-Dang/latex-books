\chapter{Enter the Router}
\label{ch:enter-the-router}

A router turns the file chapter~\ref{ch:composition} produced into an endpoint.
Point one at the config this graph composes to and it serves the subgraph
behind it, hides two of that subgraph's fields, and plans every query it is
given. There is one subgraph, so every plan has one fetch in it, which is the
best possible time to learn to read one.
