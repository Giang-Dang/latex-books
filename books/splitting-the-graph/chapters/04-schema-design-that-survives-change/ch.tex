\chapter{Schema Design That Survives Change}
\label{ch:schema-design}

A schema carries no version number, so every change you will ever want to make
has to be one you can make while the old clients are still connected.

Chapter~\ref{ch:data-without-n-plus-1} made one anyway. Paging turned
\code{sessions} from a list into a connection and broke every query written
against it, which cost nothing because the only client was you. This chapter
is what that change would have cost with somebody else's application on the
other end, and what to decide now so that the next one does not.
