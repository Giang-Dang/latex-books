\chapter{Data Without the N+1}
\label{ch:data-without-n-plus-1}

A field resolver runs once for every object it resolves, so a list of four
sessions asks for four speakers, one lookup at a time.

Chapter~\ref{ch:hot-chocolate-zero} hid that behind a list in memory, where
four lookups cost nothing and nothing counted them. A database charges for
each one and can be made to say so, which is the whole reason this chapter
moves the conference into SQLite before it fixes anything.
