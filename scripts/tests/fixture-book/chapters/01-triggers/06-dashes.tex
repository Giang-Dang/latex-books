\section{Dashes}
\label{sec:ch01-dashes}

A run of two hyphens -- like this one -- reads as an en dash in the output, and
the check reports the line once however many runs it holds.

A quotation is no escape: \enquote{the source wrote -- here} sets the same dash.

Inline code still is one: \code{--no-restore} is a flag and not a ligature.
