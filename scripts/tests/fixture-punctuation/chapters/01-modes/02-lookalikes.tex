\section{Look-alikes}
\label{sec:ch01-lookalikes}

One offender per line, so the expected line numbers stay obvious. Each is a
Unicode character that renders almost exactly like ASCII punctuation, which is
what makes it worth catching: nobody notices it by reading.

Em dash: —
Left curly quote: “
Right curly quote: ”
Ellipsis: …
No-break space between the brackets: [ ]
